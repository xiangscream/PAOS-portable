# 写作入口

按当前文稿的用途选择方法，不把每份文档都变成规范审查。

| 文稿需要 | 读取 |
| --- | --- |
| 派工、指南、TODO、交接与汇报 | [简明写作](guide-concise-writing.md) |
| 英文或中文受控技术文档 | [ASD-STE100技术写作](guide-asd-ste100.md) |
| 报告、PRD等的语言模式、信息结构和改稿方法 | [clean-writing专业方法](../../skill/clean-writing/SKILL.md) |

保留Human指定的事实、约束和必要来源。影响判断的错误与限制如实写；不用禁词清单机械删除“不确定”等真实信息。

## 内容、作者与版本

- **产品合同**：写行为、结果、理由、边界与验收条件；除已有批准约束外，不替研发选择实现。**操作指南、教程和实施方案**按任务需要可以写步骤，不套用产品合同的“只写是什么/为什么/边界”。
- **作者边界**：作者原话、观测、测量、推断与编辑者结论分别归属。授权编辑可以压缩、整理和分析，但不把口语升级成作者未确认的结论，不补造因果、指标、完成状态或“已实测”措辞。新增事实或判断要注明来源；无法确认时保留空白或交原作者。
- **版本入口**：云文档引用前核文档 ID、实际形态（主文/导师稿/展板等）和 revision；普通本地材料核路径与已有版本标记，不要求所有文件另造 revision 或 ID。活文档用于当前判断前读最新 revision，已采用版本引用已保存的准确原件。版本号相同不代表用途相同。
- **复用**：语言与结构方法继续用[简明写作](guide-concise-writing.md)、[ASD-STE100](guide-asd-ste100.md) 或 [clean-writing](../../skill/clean-writing/SKILL.md)；本页只补内容、作者与版本边界，不复制第二套写作手册。
