# Daily summary output template

Choose base or multi-workline based on how many work lines are active. Omit empty sections rather than filling them with generic text.

---

## A. Base template (1 active work line)

Use when the day is dominated by a single work line.

### 1. Manager-ready brief
Write 5–8 concise lines covering:
- the most important result;
- the main workstreams completed;
- the most important decision or definition change;
- current evidence confidence;
- the next primary task.

### 2. Detailed daily summary

# [Date or work node] 日总结

## 今日总评
One paragraph explaining what state changed today and why it matters.

## 今日直接完成
Use a table:

| Workstream | Work completed today | Result / impact | Status |
|---|---|---|---|

## 累计形成的项目状态
Include only when today consolidated earlier work. Clearly label it as cumulative.

## 关键结论与变化
For each item, use:
- Previous state;
- New state;
- Reason or evidence;
- Decision impact.

## 证据与可信度
Use a table:

| Conclusion | Evidence type | Confidence | Missing evidence |
|---|---|---|---|

## 产出物
List only meaningful artifacts. State their readiness:
- working draft;
- reviewed draft;
- accepted baseline;
- formal deliverable;
- needs revision.

## 问题、风险与未完成项
Prioritize issues that can change a decision or block the next task.

## 对目标的推进
Map the work to active objectives. State any objective that did not advance.

## 明日唯一主任务
- Task:
- Why now:
- Expected output:
- Completion definition:
- Explicit non-goals:

## 轻量辅助任务（optional, one maximum）
- Task:
- Time box:
- Completion definition:

## 今日不做 / 明日不展开
List distractions that should remain parked.

---

## B. Multi-workline template (2-3 active work lines)

Use when the day spans 2-3 parallel work lines. Each line gets its own block; the footer does cross-line synthesis.

### 1. Manager-ready brief
Write 5-8 concise lines covering **all active lines**:
- the most important result across lines;
- per-line one-liner status;
- the most important decision or definition change;
- current evidence confidence per line;
- the next primary task **per line** (up to 3).

### 2. Detailed daily summary

# [Date or work node] 日总结

## 今日总评
One paragraph explaining what state changed today **across all active lines** and why the convergence matters.

---

> **本线核心一句话**（essence statement）：把当前真相压缩成一句。
