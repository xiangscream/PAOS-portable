# 每日记录 · 怎么发（给技术人员）

**一句话：想到什么说什么，说清楚今天做完了什么、卡在哪，就行。**

- **不用填表、不用格式、不用记必填项。** 语音发出来就好。
- 说多少算多少，没说的我来补。
- 口头化、跳跃、夹杂跑题都没关系。

## 说什么

只要顺口提到下面这些里的任意几项就够（**不是要求，是提示**）：

- 今天**做完了什么**（有数字最好，比如"平衡维持 30 秒"）
- **卡在哪**、在等谁的东西
- 大概**什么时候能弄完**
- 和别人**对不上的地方**（版本不一样、零点标准不一样、接口对不上）——遇到了就说一嘴，这类最费时间

其余的（谁负责、写进哪一节、怎么表述）**都不用管，我来处理**。

# 以下为整理者内部使用，技术人员不用看

## 原始池结构

```
# LRC101 每日工作记录（原始池）
（本页为原始记录，不对外；正式进度见《LRC101 Demo1 A版｜十月开发与实验计划》）

## 2026-10-16

### 语音原始
（当天收到的音频文件名 / 链接，原样留档，不改）

### 转写稿
（AudioTranscribe 输出，按说话人分段；不改原文）

### 待确认
- （推不出来的项：目标日期、基准以谁为准 …）
```

## 整理者动作

1. 音频 → `AudioTranscribe`（带说话人分离）→ 转写稿落盘。
2. 归属到人；不确定的标「（待确认是谁）」。
3. 抽取 + 用既有材料主动补全（分工表、上一版快照、历史记录）。
4. 改写《十月计划》项目快照 + 追加阶段性进度记录。
5. 回告：改了哪几节、状态色、待确认清单（**问项目负责人，不问技术人员**）。
