> 原则：**一页以内**，让人 60 秒内答出四问——到哪了 / 变了什么 / 有什么风险 / 需要谁做什么。

## 写的时候注意

1. **状态色要诚实**：有外部等待项或关键节点延迟风险就标黄；影响交付且需上级介入标红。一路绿到周五突然红是最差实践。
2. **「需要的决定」不能长期写"无"**：若连续几期都无，说明报告只是形式，或团队不敢提问题。
3. **偏差要写影响**（延几天、影响什么节点），不要只写"延期"。
4. **承诺性问题不代答**：把问题与判断所需信息列出，交负责人回答。
5. **只有真卡点才要 owner 与日期**；已知原因、短期不解决的写「问题项」，不硬派。
