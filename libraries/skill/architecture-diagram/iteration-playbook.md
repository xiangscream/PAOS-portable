# 老板红框迭代手册（v2 新增）

> 基于智能体自进化平台架构图（2026-06-08）的实战经验。
> 老板用红框圈出问题线后，按本手册"诊断 → 修复"。

## 反馈接收最佳实践

让老板这样提反馈（你应该主动建议）：

1. 截图粘贴到对话
2. **用红框圈出**有问题的线（不要只描述"那条线"）
3. 一次最多圈 3-5 条，超过的先改前 5 条再来一轮

## 5 类典型病灶

### 病灶 1：长对角虚线斜跨整层

**症状**：一条 200-400px 的对角虚线从 L1 某节点斜跨到 L2 另一列节点。

**根因**：源节点和目标节点不在同一 x 列。

**修复**：把源节点搬到目标节点正上方（同 x 列），对角虚线变成短竖直虚线。

**案例**（评审团 → 腾讯会议）：
```
修复前：评审团(x=900) 斜线 → 腾讯会议(x=1260)  ❌
修复后：评审团(x=1260) 竖直 → 腾讯会议(x=1260)  ✓
```

### 病灶 2：多条同色箭头共用同一根 y 轴

**症状**：3 条橙色数据上报线全压在 y=395 一根水平轨道上，箭头三个挤在一起。

**根因**：多条同向同色线没有错开轨道。

**修复**：分到不同的水平轨道，**错开 20-30px**。

**案例**（三条数据上报）：
```
修复前：会话→数据A    走 y=395
        TAPD→数据B    走 y=395
        纪要→数据C    走 y=395   ❌ 三条挤一坨

修复后：会话→数据A    走 y=388
        TAPD→数据B    走 y=410
        纪要→数据C    同列竖直，不需要轨道  ✓
```

### 病灶 3：N 对 1 汇入用 N 个独立箭头

**症状**：3 条线各自带箭头进同一个目标节点（评测数据集顶部），三个箭头堆叠。

**根因**：没用干线-枝线模式。

**修复**：改用 4-cell 干线-枝线（详见 drawio-cheatsheet.md §3）：
- 3 条枝线 `endArrow=none` 汇入水平干线
- 干线中点出 1 根带箭头主线进目标

**案例**（用户/制品/转录 → 评测数据集）：
```
修复前：3 条独立箭头 → 评测集顶部，箭头堆叠  ❌
修复后：3 枝线（无箭头）→ y=595 干线 → 单根主线（带箭头）→ 评测集  ✓
```

### 病灶 4：短斜线（40-60px 偏角）

**症状**：源节点中心 x=1020，目标节点中心 x=980，画出来是个怪角度的短斜线。

**根因**：两个相邻节点中心 x 不重叠。

**修复**：让箭头的起点和终点都设在两节点重叠的 x 区间内（共用 x）。

**案例**（Skill 版本 → Git）：
```
修复前：(1020,780) → (980,873) 斜线 40px 横移  ❌
修复后：(1020,780) → (1020,873) 竖直直下     ✓
       （Git 卡片宽 180，能完全接住 1020 列）
```

### 病灶 5：长曲线穿越无关卡片

**症状**：CI/CD 回灌曲线从右下绕回左上，途中穿过 3 个业务卡片。

**根因**：箭头贪近不绕路。

**修复**：跨区箭头走"中间留白河道"或"左/右边缘"，不走业务区中间。

**案例**（回灌生产 → 会话）：
```
修复前：(290,950) → 直线 → (300,300)，穿过 L4 中枢  ❌
修复后：(290,950) → (160,950) → (160,300) → (300,300) 沿 x=160 左边缘上行  ✓
```

## 修复后必须验证

修复完每条线，**重新截图**像素级验证：
1. 这条线本身是否清晰
2. 是否引入新的交叉/重叠
3. 整体视觉是否更和谐

不达标就再改。一轮迭代不超过 10 分钟。

## 心态

老板提"还是乱"时不要慌，**逐条诊断 + 逐条修复**。一次别想做对所有线，化整为零。

每修复一条线，在内部 review 清单里打勾：
- [ ] 病灶 1：评审团对角线
- [ ] 病灶 2：橙色三条同 y
- [ ] 病灶 3：评测集汇入堆叠
- [ ] 病灶 4：Skill→Git 短斜线
- [ ] ...

修复完汇报"已修复 X 处，新的视觉效果如下截图，请 review"。
