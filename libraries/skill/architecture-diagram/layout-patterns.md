# 架构图布局模式 · 四层叙事 + 干线-枝线

## 四层叙事范式（核心结构）

观察成功案例（腾讯出行二期资金流图、微企付建议书、某头部制造企业支付替换方案），高质量架构图遵循统一的四层结构：

```
┌──────────────────────────────────────────────────────────────┐
│ Layer 1 · 入口层    y: 30~90        多列分散（用户/客户）     │
│                       ↓              ↓                ↓       │
│ ─────────────────── 虚线框 1 ─────────────────────────────── │
│ Layer 2 · 收单层    y: 188~288      单一中央节点（统一收单）  │
│                                ↓                              │
│ ─────────────────── 虚线框 2 ─────────────────────────────── │
│ Layer 3 · 中枢层    y: 378~658      单一枢纽节点（主账户）    │
│                                ↓ 干线                         │
│                       ─────────干线───────                    │
│                       ↓        ↓        ↓        ↓            │
│ Layer 4 · 出口层    y: 780~854      多列扇出（对公账户）      │
└──────────────────────────────────────────────────────────────┘
                              ↑
              左侧 x: 10~200 是体系标签区（pill + 多行说明）
```

### 各层 y 坐标参考（基于 viewBox 1640×900）

| 层 | y 范围 | 高度 | 用途 |
|---|--------|------|------|
| Layer 1 入口 | 30 ~ 90 | 60 | 用户/客户卡片 |
| (留白) | 90 ~ 188 | 98 | 入口→收单的箭头空间 |
| Layer 2 收单 | 188 ~ 288 | 100 | 虚线容器 + 中央商户号 |
| (留白) | 288 ~ 378 | 90 | 收单→中枢的箭头 + 标签空间 |
| Layer 3 中枢 | 378 ~ 658 | 280 | 大型枢纽节点 + 能力徽章 + 提示框 |
| (留白) | 658 ~ 780 | 122 | 中枢→出口的扇出箭头空间 |
| Layer 4 出口 | 780 ~ 854 | 74 | 对公账户卡片 |

## 干线-枝线连接模式

### 模式 A · N 入 1 出（汇入）

入口层 N 个节点 → 收单层 1 个节点。**做法：N 条平行竖线分别汇入虚线框上沿**。

```svg
<!-- 三家乘客（列中线 360 / 920 / 1480） → 统一商户号 -->
<line x1="360" y1="92" x2="360" y2="180" marker-end="url(#ah-blue)"/>
<line x1="920" y1="92" x2="920" y2="180" marker-end="url(#ah-blue)"/>
<line x1="1480" y1="92" x2="1480" y2="180" marker-end="url(#ah-blue)"/>
```

**关键**：箭头终点 y=180（虚线框 y=188，留 7px 让位），箭头穿过留白区进入 Layer 2 虚线框。

### 模式 B · 1 入 1 出（直通）

一条粗干线连接两层中央节点。

```svg
<!-- 收单 → 中枢 -->
<line x1="920" y1="280" x2="920" y2="370" stroke-width="2.4" marker-end="url(#ah-blue)"/>
```

**关键**：stroke-width=2.4（比枝线 2 粗），暗示主路径。

### 模式 C · 1 出 N 扇出（分账）

中枢层 1 个节点 → 出口层 N 个节点。**做法：1 条主干线下到水平干线，再 N 条枝线竖直扇出**。

```svg
<!-- 中枢出口 → 水平干线 -->
<line x1="920" y1="568" x2="920" y2="656" stroke-width="2.4"/>

<!-- 水平干线（连接 4 列） -->
<line x1="410" y1="658" x2="1370" y2="658"/>

<!-- 4 条枝线扇出到 4 个对公户 -->
<line x1="410" y1="658" x2="410" y2="772" marker-end="url(#ah-green)"/>
<line x1="730" y1="658" x2="730" y2="772" marker-end="url(#ah-green)"/>
<line x1="1050" y1="658" x2="1050" y2="772" marker-end="url(#ah-green)"/>
<line x1="1370" y1="658" x2="1370" y2="772" marker-end="url(#ah-blue)"/>
```

**关键**：
- 水平干线**没有 marker-end**（不是箭头，是连接器）
- 4 条枝线各自带 marker-end
- 同质枝线用同色（绿=分账），异质用不同色（最后一条蓝色=提现，区别于"分账"）

## 左侧体系标签区

每层对应一个体系标签，固定在 x: 10~200（180px 宽度）。

### 标签结构

```svg
<g>
  <!-- pill 主标题（实心圆角矩形 + 白字） -->
  <rect x="20" y="218" width="180" height="34" rx="17" fill="#1664FF"/>
  <text x="110" y="240" text-anchor="middle" font-size="13" font-weight="700"
        fill="#FFFFFF" letter-spacing="0.5">银行间连微信支付</text>

  <!-- 多行说明文字（左对齐 + 主色） -->
  <text x="20" y="270" font-size="11" fill="#0E42B5" font-weight="600">出行作为单一商户号收款</text>
  <text x="20" y="286" font-size="11" fill="#0E42B5">银行间连机构落地（交行等）</text>
</g>
```

### 标签 y 坐标

每个标签 pill 的 y 坐标 = 对应层的中线 y（让标签视觉上"贴齐"该层主体）：

| 层 | 主体中心 y | 标签 pill y |
|---|------------|-------------|
| Layer 2 收单 | 238 | 218 |
| Layer 3 中枢 | 508 | 448 |
| Layer 4 出口 | 817 | 700 |

## 步骤编号 + 文案标签

每个流转步骤需要：
- 一个**彩色矩形标签**（核心动作描述）
- 一个**圆形数字徽章**（步骤号）
- 一行**辅助说明文字**（细节解释）

```svg
<!-- 矩形标签 + 圆形徽章 -->
<g>
  <rect x="938" y="312" width="120" height="24" rx="3" fill="#0E42B5"/>
  <text x="998" y="329" text-anchor="middle" font-size="12.5" font-weight="700"
        fill="#fff">D+1 入主账户</text>
  <circle cx="1070" cy="324" r="12" fill="#0E42B5"/>
  <text x="1070" y="328" text-anchor="middle" font-size="11.5" font-weight="700"
        fill="#fff">2</text>
</g>

<!-- 辅助说明 -->
<text x="938" y="357" font-size="10.5" fill="#86909C">
  资金从间连微信支付商户号 D+1 提现 · 直接进入腾讯出行微企付主账户（无中间子账户）
</text>
```

**位置规则**（必须遵守 L3 让位）：
- 标签矩形 x 必须**整体推到主线一侧**，不跨越主线轴
- 辅助说明 text 也左对齐（`x` 与 rect 左边沿一致），不用 middle anchor

## 出口层标签（"分账 → XXX"）

出口层每个节点上方需要一个目的地标签，**必须在竖线右侧**（避免压线）：

```svg
<!-- ❌ 不要用 middle anchor，会骑在竖线 x=410 上 -->
<text x="410" y="760" text-anchor="middle">分账 → 小马智行</text>

<!-- ✅ start anchor + 右移 10px -->
<text x="420" y="760" text-anchor="start" font-size="10.5"
      fill="#15803D" font-weight="600">分账 → 小马智行</text>
```

## 文案规则（避免内部黑话）

❌ 不要写：三入三出 → 三入一出再扇出（黑话，外部看不懂）
✅ 改成：三家各自收单 · 三家各自结算 → 三家统一收单 · 主账户统一分账

❌ 不要写：基于 K8s 微服务架构的资金路由调度引擎
✅ 改成：分账规则引擎（按业务规则自动分账）

**原则**：每一句话都让"非技术高管"能秒懂，技术细节放脚注。
