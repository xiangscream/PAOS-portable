# 准备周四产品小组学习分享

## 摘要

用一个可复用产品判断框架组织分享，并限制准备时间。

## 当前唯一问题

如果这次分享只能让小组带走一个产品判断框架，它应该是什么？

## 阶段交付物

一份限时完成的分享材料：一个问题、一条主线、三个例子。

## 完成定义

材料可在规定时间内讲完，听众能复述框架，并且不再为了完整性增加 Slide。

## 上下文

- 固定节奏是周四分享
- 风险是为了完整性让 Slide 数量失控
- 完成定义是一个问题、一条主线、三个例子
