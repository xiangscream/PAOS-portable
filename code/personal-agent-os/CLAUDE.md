# Claude Code Entry

Claude Code 使用本仓库时，先读取 [`AGENTS.md`](AGENTS.md)。它是 PAOS 唯一的开发 Agent Guide，包含：

- 仓库职责与分层；
- 改动边界；
- 验证方式；
- PAOS 窄写协议的授权规则；
- CAT 与 Runtime 的边界。

需要执行 PAOS Prompt 中的项目要求、列表或进度窄写时，再读取 [`docs/AGENT-HANDSHAKE-PROTOCOL.md`](docs/AGENT-HANDSHAKE-PROTOCOL.md) 并严格按 Prompt 中给出的具体合同执行。

本文件只保留 Claude Code 的发现入口，不复制 `AGENTS.md` 的规则。规则发生冲突时，以 `AGENTS.md` 和对应 canonical protocol 为准。
